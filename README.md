A lightweight AirPlay server written in Python, featuring Bonjour service discovery and a sleek, customizable overlay. Designed to provide a simple and modern way to stream AirPlay content to your device.

How do i use it:
Open and install Bonjour Service (the installer is located in the folder).
Check whether the uxplay_bin folder is in the same directory as main.exe or main.py.
Open Looksmaxxerplay.exe and click Connect.
Make sure both devices are connected to the same network.
Connect your phone.

If you don't trust the EXE, you can download Bonjour Print Services from Apple here:
https://support.apple.com/de-de/106380
